Step 2: Survey Weight Normalization & Baseline Complex Survey Diagnostics
In demographic cluster surveys like the NMIS, observations do not have an equal probability of selection due to stratified two-stage cluster sampling. To generate statistically valid population estimates for rural Nasarawa State, you must account for the complex survey design immediately after value stabilization and before any partitioning or resampling occurs.
Action: Normalize the raw individual sample weight variable v005 by dividing it by 1,000,000 to obtain the true fractional analytical weights:$$\text{Analytical Weight} = \frac{\text{v005}}{1000000}$$
Execution: Run your descriptive diagnostics on the entire, un-resampled dataset using the normalized weights to compute the true population characteristics based on the following formula for any category $c$ of feature $X$:$$\text{Weighted Percentage}_c = \left( \frac{\sum_{i=1}^{n} w_i \cdot I(x_i = c)}{\sum_{i=1}^{n} w_i} \right) \times 100$$where $w_i$ is the normalized analytical weight for child $i$, and $I(x_i = c)$ is an indicator function returning 1 if the condition is met and 0 otherwise.
Deliverables:
Weighted Univariate Analysis: Quantifying baseline socio-demographic, maternal, environmental, and behavioral characteristics of your rural Nasarawa cohort.
Weighted Bivariate Analysis: Cross-tabulating each SDOH predictor against the binary microscopy outcome hml32 to calculate localized, unadjusted malaria prevalence.

Step 4: Execute Data-Level Resampling via SMOTENC
Because your rural cohort features a heavy target class imbalance where microscopy-negative records dominate positive cases, standard classifiers will suffer from a high-specificity, zero-sensitivity classification bias. However, standard SMOTE is restricted to continuous features and will corrupt your nominal categorical codes with invalid fractional decimals.
Action: Apply the Synthetic Minority Over-sampling Technique for Nominal and Continuous (SMOTENC) algorithm strictly to the training partition only.
Algorithmic Operation: Pass your tracked nominal feature index array (established in Step 1) into the algorithm configuration. For the continuous attribute b19, SMOTENC will compute standard linear interpolations between a minority instance and its $k$-nearest neighbors. For your nominal attributes (e.g., dwelling materials, net usage, water sources), it computes a modified value distance metric and assigns the local structural mode (the most frequent category among those neighbors) to the newly generated synthetic instance.
Output: A perfectly balanced training matrix ($\tilde{X}_{\text{train}}$, $\tilde{y}_{\text{train}}$) composed completely of structurally valid, non-fractional features.
Step 5: Induce White-Box Model Parity (C4.5 Decision Trees)
With your training split balanced and structurally sound, you can now generate your first intrinsically interpretable model designed to extract explicit epidemiological pathways.
Action: Configure your balanced training data within the ChefBoost framework, specifying C4.5 as the core machine learning engine.
Algorithmic Computations: The algorithm recursively constructs your classification tree by calculating Claude Shannon's Information Entropy and optimizing the split Gain Ratio at every decision node:$$H(S) = -\sum_{i=1}^{c} p_i \log_2 p_i$$$$GainRatio(A) = \frac{IG(S, A)}{SplitInfo(S, A)}$$
Pruning & Output: Run the algorithm’s bottom-up error post-pruning phase using your validation data to clip overfitted branches. Export the final decision tree topology as un-nested, human-readable IF-THEN conditional statement blocks.
Step 6: Induct Separate-and-Conquer Rulesets (RIPPER Classifier)
To discover compact, highly specific associative rulesets using an alternative logical structure, you will deploy a sequential covering architecture.
Action: Train a RIPPER (Repeated Incremental Pruning to Produce Error Reduction) classifier over your balanced training arrays using the Python wittgenstein library framework.
Mechanics: The model will isolate positive malaria instances, adding conditional antecedents to its rules by maximizing First-Order Inductive Learner ($FOIL$) Information Gain:$$FOIL_{IG} = p_1 \times \left( \log_2 \frac{p_1}{p_1 + n_1} - \log_2 \frac{p_0}{p_0 + n_0} \right)$$
Pruning & Stopping: The algorithm drops weak or overly specific rule components against an internal validation hold-out set via the incremental pruning metric $v = \frac{P - N}{P + N}$. It will automatically terminate rule generation when the Minimum Description Length (MDL) 64-bit threshold is triggered. Output the final consolidated rules list.
